## Decisiones iniciales

- React + TypeScript + Vite.
- Responsive para computadora, tableta y móvil.
- Aplicación gratuita; monetización publicitaria pendiente de aprobación.
- Sin cuenta ni backend en la primera versión; los proyectos se guardan localmente.
- Dirigida a contratistas pequeños, con modo de ejemplo para estudiantes.
- CodeGraph se usa para analizar el código fuente y facilitar su exploración; no forma parte del runtime web.
